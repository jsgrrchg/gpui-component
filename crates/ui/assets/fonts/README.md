# Bundled table fonts

Markdown tables with `TableAppearance::Plain` use Geist, matching Comet's
typography. Regular, bold, italic and bold italic are separate static faces so
the renderer can select their actual weight and style on every platform.

These files come from Comet's bundled `vercel/geist-font` release `v1.7.2`.
